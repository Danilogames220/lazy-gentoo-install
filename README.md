# Lazy Gentoo Install
Automatic script for a minimal instalation of Gentoo Linux

## About
This script was made based on the official Gentoo Linux AMD64 handbook, i made this mostly to use inside virtual machines but i think this can also work out for daily use instalations too.

## How to use:
*Warning:* do not use this script if you don't already know how to install gentoo or if this is your first time doing so, please verify each part of the script manualy before using it and caution if your using this outside of a virtual machine
*Note:* this script assumes that the disk is empty

Clone this repo in a live environment(preferably, in one of the gentoo live images), configure your own setting in the install.sh variables, then run install.sh. After so, you will be prompted for a root password, then just wait for the instalation to end, then reboot.
